# 보정용 측정값 수집 (구글 시트)

판정 기준(길·평·흉 경계)을 실제 사용자 분포로 다시 계산하기 위해, 사용자가 동의하면 **얼굴 비율값만** 구글 시트로 모은다. 사진·얼굴 좌표·이름·생년월일·위치는 보내지 않는다.

```
앱(브라우저) ──POST──▶ 구글 Apps Script 웹 앱 ──▶ 구글 시트 'raw' 탭
                                                     │
                     scripts/calibrate.mjs ◀── CSV 다운로드
                              │
                     src/lib/physiognomy.js 의 BASE 갱신
```

## 1. 시트와 받는 창구 만들기 (한 번만)

1. 구글 드라이브에서 새 구글 시트를 만든다(예: `관상 보정 데이터`).
2. 메뉴 **확장 프로그램 → Apps Script**를 연다.
3. `Code.gs` 내용을 모두 지우고, 이 저장소의 [`apps-script/Code.gs`](../apps-script/Code.gs)를 그대로 붙여 넣고 저장한다.
4. 오른쪽 위 **배포 → 새 배포**를 누른다.
   - 유형: **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. 처음 배포할 때 권한 승인 창이 뜨면 본인 구글 계정으로 승인한다. 이 스크립트는 이 시트에만 행을 추가한다.
6. 배포가 끝나면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사한다.
7. 브라우저에서 그 URL을 열어 `{"ok":true,"service":"gwansang-calibration","v":1}`이 보이면 정상이다.

> `Code.gs`를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영된다. 새 배포를 만들면 URL이 바뀌니 주의.

## 2. 앱에 연결

방법 둘 중 하나:

- **GitHub 저장소 변수(권장)**: 저장소 Settings → Secrets and variables → Actions → **Variables** 탭 → New repository variable
  - 이름 `COLLECT_URL`, 값은 위 웹 앱 URL
  - 다음 배포부터 결과 화면 아래에 '측정값 기여하기' 카드가 나타난다(Actions에서 Re-run 해도 됨).
- **코드에 직접**: `src/config.js`의 `COLLECT_URL`에 URL을 넣고 커밋.

URL은 공개돼도 되는 주소다(누구나 제출할 수 있는 창구). 대신 스크립트가 아래를 막는다.

- 값 형식·범위 검사(지표 39개, 각 −20~20, 성별·연령대·이마 상태 목록 안의 값만)
- 같은 기기에서 6시간에 10번까지만 (반복성 확인용으로 여러 번은 허용)

## 3. 시트에 쌓이는 것

`raw` 탭, 한 행 = 한 번의 측정.

| 열 | 내용 |
|---|---|
| received_at | 받은 시각 |
| v | 형식 버전(1) |
| device | 기기마다 임의로 만든 번호. 사람을 알아볼 수 없고, 같은 사람의 반복 측정을 묶는 데만 쓴다 |
| gender, age_band | 사용자가 입력한 경우만 |
| forehead | visible / covered / unclear |
| upper3, middle3, lower3 | 이마가 드러난 경우 삼정 비율 |
| aspect … noseMidHeight | 얼굴 비율값 39개 (`src/lib/contribute.js`의 METRIC_KEYS 순서) |

시트는 **본인 계정에만 공유**한다(웹에 게시하지 않는다).

## 4. 기준 다시 계산하기

1. 시트에서 `raw` 탭을 연 상태로 **파일 → 다운로드 → CSV**.
2. 실행:
   ```bash
   node scripts/calibrate.mjs ~/Downloads/관상\ 보정\ 데이터\ -\ raw.csv
   ```
3. 출력:
   - 지표별 인원·평균·표준편차·사분위, 남녀 평균
   - **반복성(ICC)**: 같은 사람을 여러 번 찍었을 때의 흔들림 대비 사람 간 차이. 0.5 미만이면 "사람 구별 못 함" 표시 → 그 지표는 판정에서 빼거나 '참고'로 둔다.
   - `BASE`에 붙일 값(30명 이상 모인 지표만 바꾸고 나머지는 기존 값 유지)
4. 출력된 `BASE`를 `src/lib/physiognomy.js`에 반영하고 `npm test`.

### 목표 표본

| 단계 | 필요한 것 |
|---|---|
| 반복성 확인 | 20명 × 각 5번 (같은 기기에서 다시 찍어 보내기) |
| 베타 기준 | 남녀 각 50명 이상 |
| 정식 기준 | 남녀 각 150명 |

같은 사람이 여러 번 보내도 분포 계산에는 기기별 평균 한 번만 들어간다.

## 5. 한계 (알고 쓰기)

- 구글 시트는 수만 행부터 느려지고, Apps Script는 하루 실행 횟수 한도가 있다. 정식 출시 후 사용자가 많아지면 DB(Supabase 등)로 옮긴다. 시트의 열 구조를 그대로 표로 옮기면 된다.
- 기기 번호는 브라우저 저장소에 있어서, 저장소를 지우거나 다른 브라우저를 쓰면 다른 사람으로 잡힌다. 그래서 하루 제출 한도는 스팸을 완전히 막지는 못한다. 보정 계산 전에 시트에서 이상한 묶음(같은 시각에 대량, 같은 값 반복)을 눈으로 한 번 확인한다.
- 구글 서버는 국외에 있을 수 있어, 동의 문구에 "구글 시트(국외 포함)에 저장"을 밝혔다.
