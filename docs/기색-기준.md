# 기색(氣色) 기준 — 얼굴 안에서 비교하기

출처: 『增補麻衣相法全編』 p33~40(십이궁·부모궁), p162~165(氣色). 결정: 2026-10-07.

## 1. 원전이 말하는 기색

- 관찰 조건(p162): 「氣色最爲難審 須于清明昧爽 精氣不亂之時觀之」 — 맑은 날 동트기 직전, 정기가 흐트러지지 않았을 때.
- 바뀌는 주기(p162): 「氣色半月一換」 — 보름마다 바뀐다.
- 좋고 나쁨의 기준(p163~164): 같은 빛깔도 **윤택하면(潤澤) 길하고**, 마르고 어둡거나(枯·暗·烟煤) 들끓으면(焦烈) 흉하다.
- 신(神)이 우선(p165): 「以上氣色雖現 尤要看神色 正而神旺 色終莫能爲大禍」 — 기색이 나타나도 신이 바르고 왕성하면 큰 화가 되지 못한다.

## 2. 우리 방식 (원전 조건에서 바꾼 점)

| 원전 | 앱 | 이유 |
|---|---|---|
| 동트기 직전 | **밝은 곳**에서 촬영 | 사용자 부담. 대신 아래 비교 방식으로 조명 영향을 줄인다 |
| 얼굴빛 자체 | **같은 사진 안에서 부위 빛깔 − 두 뺨 빛깔** (CIE Lab의 밝기 dL·붉음 da·누름 db) | 조명 색·카메라 화이트밸런스는 얼굴 전체에 같이 걸리므로 차이를 내면 대부분 지워진다 |
| 윤택함(潤澤) | 재지 않음 | 피부 광택은 피지·조명 반사에 좌우된다. 반사광(L>92)은 오히려 빼고 잰다 |
| 신(神) | 재지 않음 → 흉한 기색에는 p165 구절을 늘 함께 싣는다 | |

촬영 검사(통과 못 하면 기색은 판정하지 않음): 두 뺨 밝기 L<35(어두움), 두 뺨 밝기 차 >8(한쪽 조명 — 그림자를 기색으로 오인), 반사광 20% 초과.
부위 안에서 기준 피부와 빛깔이 크게 다른 픽셀(배경·머리카락·흰자)은 뺀다.

## 3. 판정 (원전에 '부위 + 빛깔'이 함께 나온 구절만)

| 부위 | 빛깔 | 원문 | 등급 |
|---|---|---|---|
| 인당(명궁) | 明 | 光明如鏡 學問皆通 (p33) | 길 |
| 중정(관록궁) | 明 | 光明瑩淨 顯達超群 (p36) | 길 |
| 어미·간문(처첩궁) | 明 | 光潤 (p35) | 길 |
| 준두(재백궁) | 明 | 豐滿明潤 財帛有餘 (p33) | 길 |
| 일월각(부모궁) | 赤·黃 | 紅黃 主雙親喜慶 (p39) | 길 |
| 일월각 | 青 | 青 主父母憂疑 (p39) | 흉 |
| 일월각 | 黑 | 黑白 主父母喪亡 (p39) | 흉 |
| 연상·수상 | 黃 (사계월 3·6·9·12월) | 四季月年壽宜黃 (p165) | 길 |
| 연상·수상 | 白 / 赤 / 青 / 黑 | 白主服 / 紅主訟及瘡疾破財 / 青主驚恐疾病 / 黑主大病死亡 (p165) | 흉 |
| 산근(질액궁) | 赤+暗 | 紅色 … 黑氣者 主大禍 居疾厄主死 (p164) | 흉 |
| 중정(관록궁) | 赤+暗 | … 居官祿主降官失職 (p164) | 흉 |

빛깔 정하기(두 뺨 대비, Lab 단위, 임시값): 明 dL>+7, 暗 dL<−7, 黑 dL<−11, 赤 da>+5, 黃 db>+5(붉지 않을 때), 青 da<−2.5 그리고 db<−2.5, 白 밝으면서 붉지도 누르지도 않음.
이마·코끝은 원래 빛을 더 받아 밝게 찍히므로 밝기에서 추정 몫을 먼저 뺀다(중정 3, 코끝 6, 콧대 3, 일월각 2).

## 4. 한계와 보정

- 임계값과 '원래 밝은 몫'은 추정치다. 측정값 기여에 부위별 차이(cxMyungL 등 21개)를 함께 모아(Supabase), 부위별 보통 사람의 차이를 구해 다시 정한다.
- 사계월은 원전이 음력 기준이다. 지금은 양력 3·6·9·12월로 근사한다.
- 화장·선크림·필터는 사진으로 알 수 없다. 촬영 안내에 "맨얼굴·필터 끔"을 넣는다.
- 본인 사진 5장: 부위별 차이가 장마다 ±0.5 안으로 일정했고, 판정에 걸린 기색은 없었다.
