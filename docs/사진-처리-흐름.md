# 사진을 넣으면 무엇이 일어나고 무엇이 나오는가

현재 코드(`src/main.js`, `src/face.js`, `src/lib/*.js`) 기준 정리. 판정 원칙은 [`관상-기준.md`](관상-기준.md).

## 1. 입력

| 항목 | 필수 | 쓰임 |
|---|---|---|
| 동의 2개 (만 14세 이상, 기기 안 분석) | 필수 | 체크해야 카메라·사진 버튼이 켜짐 |
| 사진 1장 **또는** 카메라 촬영 | 필수 | 카메라는 1초 동안 5장을 찍어 평균 |
| 태어난 해 | 선택 | 유년운기(올해 운을 맡는 자리) |
| 성별 | 선택 | 男左女右(좌우 중 어느 쪽을 볼지), 성별에 따라 다른 원문(男人口闊 / 女人口闊) |

권장 촬영 조건: 정면, 무표정, 밝은 곳, **이마를 드러냄(앞머리를 넘김)**.

## 2. 처리 순서

모든 처리는 사용자 브라우저 안에서만 한다. 서버로 보내는 것은 없다(§6의 '측정값 기여'에 동의한 경우만 예외).

```
사진/촬영
  │ ① 얼굴 찾기 ─ MediaPipe Face Landmarker: 얼굴 점 478개 + 표정 값
  │ ② 거부 검사 ─ 얼굴 없음 / 2명 이상 / 웃음 / 입 벌림 / 옆으로 돌림 / 기울임
  │ ③ 측정 ─ 얼굴 점 → 비율값 39개 (카메라면 5장 평균)
  │ ④ 이마 검사 ─ 머리카락 분할 모델로 머리선 찾기 → 드러남 / 가림 / 불명확
  │ ⑤ 판정 ─ 비율값을 기준 분포와 비교 → 길·평·흉 + 원문 인용 (23개 항목)
  │ ⑥ 운기 ─ 태어난 해가 있으면 올해~4년 뒤의 담당 자리 판정
  │ ⑦ 그림 ─ 비율값만으로 얼굴을 다시 그려 십이궁도·유년운기도 생성
  ▼ ⑧ 결과 화면
```

### ② 거부 조건과 안내 문구

| 조건 | 안내 |
|---|---|
| 얼굴을 못 찾음 | 얼굴을 찾지 못했어요. 밝은 곳에서 정면으로 다시 찍어 주세요. |
| 2명 이상 | 한 사람만 나온 사진으로 해 주세요. |
| 웃음 (smile > 0.4) | 웃으면 입과 눈 비율이 달라져요. 무표정으로 찍어 주세요. |
| 입 벌림 (jawOpen > 0.25) | 입을 다물고 찍어 주세요. |
| 좌우로 돌림 | 얼굴이 옆으로 돌아가 있어요. 정면을 봐 주세요. |
| 20° 넘게 기울임 | 고개가 많이 기울어져 있어요. 똑바로 해 주세요. |

거부되면 결과 없이 첫 화면에 머문다.

### ③ 측정하는 것 (비율값 39개)

모두 얼굴 너비, 눈 길이처럼 얼굴 안의 길이로 나눈 **비율**이라 사진 크기와 무관하다. 고개 기울기는 두 눈을 수평으로 맞춰 보정한다.

- **너비·길이**: 얼굴 가로세로, 이마 너비, 턱선 너비, 턱 끝 너비, 인당(미간) 너비, 콧방울 너비, 입 너비, 콧대 길이, 인중 길이
- **눈썹·눈**: 눈썹 길이, 눈썹 끝이 눈꼬리를 넘는 정도(眉長過目), 눈썹과 눈 사이, 눈 가로/세로(細長), 눈꼬리 방향(目尾), 눈 크기
- **입**: 입꼬리 방향(口角), 윗입술·아랫입술 두께
- **좌우**: 얼굴 대칭, 이마 기울기, 눈썹 높이 차이
- **깊이 추정(참고)**: 산근 높이, 연상·수상 높이, 광대 돌출, 간문(눈꼬리 옆), 누당(눈 밑)
- 좌우가 있는 것은 왼쪽·오른쪽을 따로도 잰다(男左女右용).

### ④ 이마 검사

| 결과 | 조건 | 효과 |
|---|---|---|
| 드러남 | 머리선을 찾음 | 머리선~눈썹, 눈썹~코밑, 코밑~턱끝으로 삼정 측정 |
| 가림 | 눈썹 가까이에서 머리카락이 잡힘 (앞머리) | 상정·삼정 균형·이마 위 운기(15~19·22·25세)·관록궁의 이마 높이를 **판정하지 않음**, "상정은 명확하지 않아요" 표시 |
| 불명확 | 이마 위가 사진 밖으로 잘림, 또는 머리선을 못 찾음(모자·민머리) | 가림과 같음 |

## 3. 결과 화면 (위에서 아래 순서)

| # | 섹션 | 내용 |
|---|---|---|
| 0 | 이마 안내 (가림·불명확일 때만) | 이유 + 원문 「髮際至印堂 上停」 + **다시 찍기** 버튼 |
| 1 | **총평** | "○○궁(분야)이 가장 좋은 얼굴" / 약한 자리, 귀·부·수·전 네 기둥(達磨相訣 第五法: 귀=눈, 부=코, 수=신(보지 않음), 전=소리(보지 않음)), 가장 좋은 궁의 원문, 13궁 한눈에 보기 |
| 2 | **유년운기** | 올해 운을 맡은 자리와 판정 + 원문, 5년 흐름표, 자리가 바뀌는 해 안내. 태어난 해가 없으면 선택 창 |
| 3 | **관상도** | 비율로 다시 그린 얼굴 위에 십이궁도 / 유년운기도(전환). 이미지 저장 |
| 4 | 저장·공유 버튼 | 결과 이미지(9:16), 공유 링크 |
| 5 | **삼정** | 상·중·하정 비율(%)과 三停平等/不均 판정 (이마 가림이면 "판정하지 않음") |
| 6 | **오관** | 보수관(눈썹)·감찰관(눈)·심변관(코)·출납관(입)·채청관(귀: 보지 않음), "네 관 중 n개 이루어짐", 인중 |
| 7 | **오악** | 남악(이마)·동서악(광대)·중악(코)·북악(턱) |
| 8 | **십이궁** | 명궁, 재백궁, 형제궁, 전택궁, 남녀궁, 노복궁, 처첩궁, 질액궁, 천이궁, 관록궁, 복덕궁, 상모궁, 부모궁 (13개) |
| 9 | **관계로 보는 자리** | 형제·벗 / 배우자 / 자녀 / 아랫사람 / 부모별로 해당 궁 판정 모음 |
| 10 | **사진으로 보지 않은 것** | 기색, 신(눈빛), 소리, 귀, 점·주름, 오행형과 그 이유 |
| 11 | 측정값 기여 (수집 주소가 설정된 경우만) | 동의 후 비율값만 전송 |

### 판정 하나의 모양

```
[궁 이름] [한자]  [참고]        [길 / 평 / 흉 / —]
[위치 · 분야]
[측정 결과를 원전 형상어로]   예: 두 눈썹 사이가 좁다
  「원문」 출처(책·쪽)
  현대어 직역
[보지 않은 조건 안내]          예: 인중의 깊이는 사진으로 보지 않았다
```

- **길·흉**: 원문과 직역을 그대로 싣는다(흉도 그대로).
- **평**: 원전이 길흉을 말하는 범위에 들지 않음. 원문 없이 측정 결과만 표시한다.
- **— (보지 않음)**: 사진으로 판정할 수 없는 자리.
- **참고**: 깊이 추정값을 쓴 판정(산근·광대·누당·간문 등).

판정 수: 삼정 1 + 오관 4(귀 제외) + 인중 1 + 오악 4 + 십이궁 13 = **23개**, 그리고 운기 5년.

## 4. 결과 이미지 (9:16)

위에서부터 관상도 → 총평 한 줄 → 가장 좋은 궁의 원문·직역 → 올해 운기 → 오관 성립 수 → (가림이면) "상정 판정하지 않음" → 출처 표기.

## 5. 저장되는 것 (이 기기의 브라우저에만)

| 저장 | 저장 안 함 |
|---|---|
| 비율값 39개, 이마 검사 결과, 태어난 해, 성별, 동의 여부 | 사진, 얼굴 점 좌표 |

다시 접속하면 저장된 비율값으로 결과를 바로 다시 보여 준다. '내 기록 지우기'로 삭제할 수 있다.

## 6. 밖으로 나가는 것

- 기본: 없음.
- '측정값 기여하기'에 동의한 경우만 비율값 39개, 이마 상태, 삼정 비율, 성별, 연령대, 기기 임의 번호를 구글 시트로 보낸다([`데이터-수집.md`](데이터-수집.md)).

## 7. 예시 (테스트 사진 1장, 남, 1985년생, 이마 드러남)

| 구분 | 결과 |
|---|---|
| 총평 | 재백궁(재물)이 가장 좋은 얼굴 / 약한 자리 명궁 · 길 6, 흉 2(상모궁 제외) |
| 삼정 | 29 / 32 / 39% → 흉 「三停不均 孤夭貧賤」 |
| 오관 | 보수관 흉 「眉環塞眼 兄弟疏」, 감찰관 길 「目秀而長 近君王」, 심변관 길, 출납관 길 「口闊唇方 必定有財有祿」·「男人口闊 喫十方」 → 4개 중 3개 |
| 오악 | 남악 평, 동서악 흉(참고), 중악 길, 북악 길 |
| 십이궁 | 길: 재백·남녀·노복·질액·천이·복덕 / 흉: 명궁 「眉接交加 貧賤」, 형제, 상모 / 평: 전택·처첩·관록·부모 |
| 운기 | 2026~27 정사·광전 길 → 2028~29 연상·수상 길 → 2030 광대 흉 |

※ 이 사진은 웃는 얼굴이라 실제 앱에서는 ②에서 거부된다. 판정 모양을 보이려고 측정값을 직접 넣은 예시다.

## 8. 알려진 문제

1. **같은 측정값이 여러 판정에 겹쳐 쓰인다.** 예시에서 '눈썹과 눈 사이가 좁다' 하나가 보수관 흉과 형제궁 흉을 동시에 만들었다. 인당 너비도 명궁·천이궁·부모궁에 함께 쓰인다. 측정 하나가 틀리면 흉이 여러 개로 불어난다.
2. **원문의 조건 일부만 재고 원문 전체를 인용하는 경우가 있다.** 예: 질액궁 길의 「山根連鼻梁 豐隆而起 與額平 位至三公」은 '이마와 평평함(與額平)'을 재지 않았다.
3. **길·평·흉 경계가 아직 보정 전이다.** 예시처럼 실제 얼굴에서 흉이 쉽게 나올 수 있다. 측정값 수집 후 다시 계산해야 한다.
4. **판정이 23개라 화면이 길다.** 결과 이미지에는 총평·운기·오관만 들어간다.
5. **서비스 제목 "내가 왕이 될 상인가?"와 내용이 맞지 않는다.** 왕 판정은 원전 근거가 없어 지웠다.
6. **사진 올리기 때 사진의 위치 정보(EXIF)를 읽는 코드가 남아 있다.** 잠가 둔 '이 자리' 기능용이다. 저장·전송하지 않지만 무료 흐름에서는 읽을 필요가 없다.
