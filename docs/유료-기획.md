# 유료 관상 「내가 왕이 될 상인가?」 기획 (초안)

결정(2026-10-06): 무료 결과 없이 **유료 버전 하나로** 간다. 이 문서는 그 유료 버전의 상품·흐름·결과 구성·기술·운영을 정한다. 판정 원칙은 [`관상-기준.md`](관상-기준.md)를 그대로 따른다.

---

## 1. 무엇을 파는가

**"내 얼굴로 본, 내 고민에 대한 관상 해설"** — 사진 측정(원전 판정) + 사용자가 적은 고민 + 그것을 엮은 해설.

참고 서비스(사주아이)에서 가져올 것:

| 가져올 것 | 이유 |
|---|---|
| 고민 입력 | 모든 해설이 '내 이야기'가 되는 가장 큰 장치 |
| 제목만 훑어도 재밌는 목차 + 펼쳐 읽기 | 긴 해설을 끝까지 보게 만드는 구조 |
| 생활 주제 목차(재물복·연애운·나에게 맞는 일…) | 궁 이름 같은 전문 용어 대신 |
| "쓴소리 좀 할게" 칸 | 흉 판정을 원문 그대로 실으면서도 읽을 만하게 |
| 전문성 증거는 맨 위 한 번 | 사주의 만세력 표 → 우리는 **내 얼굴 관상도** |
| 다 읽은 뒤 후속 질문·다른 상품 | 재구매 |

우리만의 차별점: **내 얼굴 사진 위에서 자리를 짚어 주는 것**, 그리고 **원전(마의상법·상리형진) 근거**.

## 2. 상품 구성 (첫 출시)

| 상품 | 내용 | 가격(가안) |
|---|---|---|
| **정밀 관상** (대표) | 정면 사진 + 고개 돌리기 3초 스캔, 생년·성별·고민 → 해설 14칸 + 관상도 + 올해 운기 | 990원~ (§8 결정 필요) |
| 후속 질문 | 결과를 본 뒤 "내 고민, 그래서 어떻게?" 등 질문 1개 추가 해설 | 대표 상품보다 낮게 |
| (2차) 관상 궁합 | 두 사람이 각자 찍어 링크로 합침 → 형제궁·처첩궁 등 관계 자리 비교 | 2차 |
| (2차) 올해 운기 상세 | 유년운기 5년 + 해당 자리 상세 | 2차 |
| (보류) 관상 × 사주 | 연결점은 사용자가 정한 뒤 | — |

## 3. 사용자 흐름

```
① 첫 화면 ─ "내가 왕이 될 상인가?" + 예시 결과 미리보기(샘플 인물)
② 촬영 ─ 정면 1장(무표정·이마 드러냄) → 고개 천천히 좌우 3초
     · 거부 조건: 얼굴 없음/2명/웃음/입 벌림/돌림/기울임/이마 가림
③ 입력 ─ 태어난 해, 성별, 고민(선택이지만 강하게 권함, 300자)
④ 미리보기(결제 전) ─ 내 얼굴 관상도 + 13궁 길·흉 칩 + 해설 14칸의 '제목만'
⑤ 결제 ─ 비회원 결제(휴대폰 번호 또는 이메일로 결과 다시 보기)
⑥ 생성 연출 ─ "이마부터 턱까지 보는 중…" (해설 생성 시간 동안)
⑦ 결과 ─ §4 구성
⑧ 끝 ─ 마스코트 쪽지 + 후속 질문 3개(유료) + 공유 링크·이미지 저장 + 다른 상품
```

### 왜 ④ 미리보기가 필요한가 (유료 전용의 허점)
무료 결과를 없애면, 사용자는 **아무것도 못 본 채 돈을 내야** 한다. 사진까지 찍게 한 뒤 바로 결제창이 나오면 이탈이 크다. 그래서 **결과가 아니라 '내 얼굴이 이미 분석됐다는 증거'**를 먼저 보여 준다.
- 내 얼굴 위 관상도, 13궁 길·흉 칩(해설은 가림), 해설 14칸의 제목.
- 판정 계산은 기기 안에서 끝나므로 이 단계까지는 비용이 0이다. 비용(해설 생성)은 결제 후에만 생긴다.

참고 서비스도 '오늘의 무료 운세', '하루 한 번 무료 상담'을 따로 둬서 유입을 만든다. 완전 유료 전용은 유입 장치를 따로 고민해야 한다(§9).

## 4. 결과 화면 구성

맨 위: **내 얼굴 관상도**(사진 위에 13궁·유년운기 자리 표시, 사진은 화면에만) + 입력 정보 + 내가 적은 고민 + 「관상도 자세히 보기 >」(13궁 길·흉 표).

해설 14칸 — 각 칸은 **제목 한 줄(눌러서 펼침) → 본문 → 근거 원문 1~2개(작게)**.

| # | 칸 | 쓰는 판정 | 제목 예 (형식만) |
|---|---|---|---|
| 1 | 한마디로 | 총평(가장 좋은 궁·약한 궁) + 고민 | "○○가 붙는 얼굴, 그런데 고민은 △△?" |
| 2 | 얼굴 세 마디로 보는 인생 | 삼정·오악 | 초년·중년·말년 중 언제 피는 얼굴인가 |
| 3 | 눈·코·입이 말하는 것 | 오관(4관 중 몇 개 이루어짐) | |
| 4 | 쓴소리 좀 할게 | 흉 판정 모음 (원문·직역 그대로) | |
| 5 | 나만의 매력 | 길 판정 모음 | |
| 6 | 나라는 사람 | 명궁·감찰관 | |
| 7 | 나에게 맞는 일 | 관록궁·천이궁·출납관 + 고민 | |
| 8 | 재물복 | 재백궁·준두·지고 | |
| 9 | 연애운 | 처첩궁·눈꼬리(目尾)·산근 | |
| 10 | 가족 인연 | 부모궁·형제궁·남녀궁 | |
| 11 | 곁에 둘 사람 | 형제궁·노복궁·「擇交在眼」 | |
| 12 | 올해의 얼굴 | 유년운기(올해 자리 + 앞으로 4년) | |
| 13 | 내 고민, 관상으로 보면 | 고민 + 관련 궁 | (고민을 안 적었으면 숨김) |
| 14 | 마지막 한마디 | 총평 | |

원칙:
- **원문은 측정한 조건까지만** 인용(기준서 §5). 정밀 스캔으로 잰 조건(산근 높이, 인중 깊이 등)이 늘어나므로 무료 시절보다 인용할 수 있는 원문이 많아진다.
- 흉은 원문·직역을 바꾸지 않는다. 제목과 이어지는 본문의 말투로 읽을 만하게 만든다.
- '평'만 있는 칸은 짧게 쓴다(지어내지 않는다).

## 5. 해설은 누가 쓰나 — AI + 원전 판정으로 묶기

고민을 엮은 맞춤 해설은 고정 문구 조합으로는 어렵다. **AI(LLM)가 쓰되, 판정과 원문은 우리가 정한 것만 쓰게 묶는다.**

```
[기기]  사진 → 측정 → 원전 판정(JSON)            ← 사진·좌표는 기기 밖으로 안 나감
           │ 판정 JSON + 생년·성별 + 고민
[서버]  결제 확인 → AI 호출 → 출력 검사 → 결과 저장
           │ 칸별 {제목, 본문, 인용원문[]}
[기기]  결과 화면
```

AI에게 주는 것과 지킬 규칙:
- 입력: 칸별로 **쓸 수 있는 판정**(궁·등급·측정 결과)과 **인용 가능한 원문 목록**, 고민.
- 규칙: 목록 밖 원문 금지, 판정 등급을 바꾸지 말 것, 흉은 직역을 그대로 포함, 오행형·궁합·개운법 금지(기준서 §4·§6), 의료·법률 단정 금지.
- **출력 검사(서버)**: 인용 원문이 허용 목록과 글자 단위로 일치하는지, 등급이 판정과 같은지 확인. 어긋나면 그 칸만 다시 생성.
- 모델과 건당 비용은 구현 때 정한다(가격 결정 §8과 함께).

## 6. 정밀 측정 (유료에서 새로 하는 것)

| 지금(정면 1장) | 정밀(정면 + 고개 돌리기 3초) |
|---|---|
| 산근·연상·수상·준두 높이: 깊이 추정 | 여러 각도에서 직접 계산 |
| 광대·간문·누당: 깊이 추정 | 솟음·꺼짐 측정 |
| 턱 앞으로(地閣 朝·厚), 이마 솟음(骨起): 불가 | 옆 윤곽에서 측정 |
| 인중 깊이: 불가 | 옆 각도에서 일부 측정 |
| 귀: 불가 | 보이긴 함, 판정은 귀 인식 모델 확보 후 |

스캔 중 안내: 화면에 얼굴 윤곽 가이드와 "왼쪽으로 천천히 → 오른쪽으로" 진행 표시. 각도 범위가 부족하면 다시.

## 7. 기술 구성

지금은 서버 없는 정적 사이트(GitHub Pages). 유료에는 **서버가 반드시 필요**하다.

| 필요한 것 | 이유 | 제안 |
|---|---|---|
| 결제 | 결제 승인 확인(위변조 방지)은 서버에서 | 토스페이먼츠 또는 포트원 |
| AI 호출 | API 키를 브라우저에 둘 수 없음 | 서버 함수 |
| 주문·결과 저장 | 비회원 재조회, 공유 링크, 환불 처리 | DB |
| 이미지·PDF | 공유 이미지, PDF 저장 | 기기에서 생성(지금처럼) |

**Supabase**(DB + 서버 함수 + 서울 리전)를 권한다. 보정용 측정값 수집은 지금처럼 구글 시트로 두고, 주문·결과는 DB로 분리한다.

저장하는 것 / 안 하는 것:
- 저장: 주문 정보, 판정 JSON(비율값 아님), 고민, 생성된 해설, 연락처(재조회용).
- 저장 안 함: 사진, 얼굴 좌표, 비율값 원본.
- 보관 기간을 정해 지난 결과는 지운다(예: 1년, §8).

## 9. 유료 전용의 허점과 대응

1. **유입**: 무료로 써 볼 것이 없으면 입소문 고리가 약하다. → 공유된 결과 링크를 받은 사람은 그 사람의 결과(일부)를 볼 수 있게 하고, "나도 보기"로 연결. 결과 공유가 사실상의 무료 맛보기가 된다.
2. **기준 보정 데이터**: 측정값 기여는 무료 사용자에게 기대던 것. 유료 사용자는 적어서 표본이 느리게 쌓인다. → 출시 전 지인·테스터로 반복성 20명 × 5회와 베타 100명을 먼저 채운다([`데이터-수집.md`](데이터-수집.md)).
3. **판정이 틀리면 돈을 낸 사람이 흉을 받는다.** 기준이 보정되기 전 출시는 환불·불만으로 이어진다. → 보정 전에는 베타(무료 테스터) 기간을 둔다.
4. **환불**: 디지털 콘텐츠는 제공이 시작되면 청약철회가 제한될 수 있지만, 그러려면 결제 전에 그 사실을 분명히 알려야 한다(전자상거래법). 생성 실패·사진 거부 시 자동 환불 규칙 필요.
5. **사업 요건**: 사업자등록, 통신판매업 신고, 개인정보처리방침, 이용약관. 운세·점술 업종은 PG 심사에서 추가 확인을 요구할 수 있으니 PG에 미리 문의.
6. **만 14세 미만**: 결제·개인정보 모두 법정대리인 동의가 필요하므로 계속 막는다.
