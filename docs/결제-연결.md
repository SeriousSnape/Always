# 결제·서버 연결 (Supabase + 토스페이먼츠 + Claude)

```
[브라우저]  사진 → 측정·판정(기기 안) → '정밀 관상 받기'
    │ ① create-order: 판정 재료(brief: 등급·원문·고민)만 보냄 → 주문 + 금액(서버가 정함) + 결과 열쇠
    │ ② pay.html: 토스 결제위젯 → 결제
    │ ③ confirm-payment: 서버가 토스에 승인 요청(금액은 DB 값과 대조) → paid
    │      └ 뒤에서 Claude 해설 생성 → 출력 검사 → orders.narrative 저장 → done
    └ ④ result.html?order=…&token=…: get-result 로 기다렸다가 표시. 링크만 있으면 다시 볼 수 있음
[Supabase]  orders 표(사진·좌표·비율값·연락처 없음), calibration_samples 표
```

## 단계 (지금은 테스트 기간 — 무료)

| 상태 | 넣은 값 | '정밀 관상 받기'를 누르면 |
|---|---|---|
| ① 아무것도 없음(지금) | — | 기기 안에서 판정 + **원문 풀이**로 15칸을 채움(AI 아님, 서버 저장 없음) |
| ② Supabase + Claude 키 | SUPABASE_*, ANTHROPIC_API_KEY (`FREE_MODE` 기본 true) | 결제 없이 **AI 해설 생성 → Supabase 저장 → 결과 링크**. 남용 방지: 하루 전체 40건, 같은 사람(IP 해시) 하루 3건 |
| ③ 결제 붙이기 | + TOSS 키, 저장소 Variable `FREE_MODE`=`false` | 토스 결제 → 승인 → AI 해설 |

②에서는 토스 키가 필요 없다(TOSS_SECRET_KEY 는 비워 둬도 됨). 한도는 함수 Secrets `FREE_DAILY_CAP`, `FREE_PER_CLIENT` 로 바꾼다.

## 1. 계정과 키 (관영님이 직접)

| 어디서 | 받을 것 | 넣을 곳 |
|---|---|---|
| supabase.com → New project (Region: Seoul) | Project ref(URL의 `https://<ref>.supabase.co`), anon 키(Settings → API), DB 비밀번호(만들 때 정함) | 아래 표 |
| supabase.com → Account → Access Tokens | Access token | 아래 표 |
| developers.tosspayments.com 가입 → 개발 정보 → **결제위젯** 연동 키 | 클라이언트 키 `test_gck_…`, 시크릿 키 `test_gsk_…` | 아래 표 |
| console.anthropic.com → API Keys | `sk-ant-…` | 아래 표 |

테스트 키는 가입만 하면 바로 나온다(사업자 없어도 됨). **실 결제**는 사업자등록 + 통신판매업 신고 + 토스 전자결제 계약·심사가 필요하고, 운세·점술 업종은 심사에서 추가 확인을 요구할 수 있다(미리 문의).

## 2. GitHub 저장소 설정 (Settings → Secrets and variables → Actions)

**Secrets** (비밀, 화면에 안 보임)

| 이름 | 값 |
|---|---|
| `SUPABASE_ACCESS_TOKEN` | Supabase Access token |
| `SUPABASE_DB_PASSWORD` | DB 비밀번호 |
| `TOSS_SECRET_KEY` | `test_gsk_…` |
| `ANTHROPIC_API_KEY` | `sk-ant-…` |

**Variables** (공개돼도 되는 값)

| 이름 | 값 |
|---|---|
| `SUPABASE_PROJECT_REF` | Project ref |
| `SUPABASE_URL` | `https://<ref>.supabase.co` |
| `SUPABASE_ANON_KEY` | anon 키 |
| `TOSS_CLIENT_KEY` | `test_gck_…` |
| `PRICE` | 가격(원, 기본 990) |

넣은 뒤 Actions 탭에서 **Deploy Supabase** 와 **Deploy to GitHub Pages** 를 Run workflow. 앞의 것이 표(orders, calibration_samples)를 만들고 함수 셋(create-order, confirm-payment, get-result)을 올린다. 뒤의 것이 앱을 다시 빌드한다.

1. https://serioussnape.github.io/Always/ 에서 사진 → '정밀 관상 받기' → 결제창(테스트 카드로 결제)

3. Supabase → Table Editor → `orders` 에 status `done` 행이 생겼는지.

## 4. 비용·시간

- 해설 1건: Claude Opus 5.5 (입력 $4 / 출력 $20 per 100만 토큰). 판정 재료 약 6천 토큰 + 출력 6천~1만 토큰(생각 포함) → **건당 약 $0.15~0.25 (200~350원)**, 검사에 걸려 다시 쓰면 더. 990원이면 결제 수수료(약 3%대 + 건당 최소 수수료 여부)까지 빼고 남는 게 얇다 → 가격 결정 때 함께 볼 것. 모델은 함수 Secrets 의 `CLAUDE_MODEL` 로 바꿀 수 있다.
- 생성 시간: 1~2분. Supabase 무료 요금제는 함수 실행 시간이 짧아(약 150초) 넘으면 끊길 수 있다. 끊기면 결과 화면이 3분 뒤 자동으로 다시 생성한다(최대 3번). 자주 끊기면 Pro 요금제 또는 effort 를 낮춘다.
