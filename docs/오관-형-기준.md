# 오관의 형(形) 기준 — 닮은 형과 대표 부위

출처: 『增補麻衣相法全編』 권2 그림 표 (스캔 PDF 쪽). 결정: 2026-10-07.

## 1. 원칙

1. 오관(눈썹·눈·코·입·귀)마다 원전 그림 표의 형 가운데 **가장 닮은 형**을 고른다.
2. 첫 화면의 '닮은 형' 후보는 원전 표시(그림 위 글자)가 **길한 형만**. **흉한 형도 따로 판정해서, 걸리면 '쓴소리' 칸에 원문과 직역을 그대로 싣는다**(결정 2026-10-07). 그래서 한 관이 첫 화면에서는 좋은 형으로, 쓴소리 칸에서는 흉한 형으로 동시에 나올 수 있다 — 원전도 한 부위를 여러 형으로 견준다.
3. 고르는 기준은 원전 그림과 시에 나온 **모양**만. 빛깔(紅·黃), 털결(濃·疏), 눈빛(神), 소리는 재지 않는다.
4. **대표 부위**: 그 관에 딸린 판정 중 길한 수가 가장 많은 관(눈: 감찰관·전택궁 / 눈썹: 보수관·형제궁 / 코: 심변관·재백궁·중악 / 입: 출납관). 같으면 達磨 비중(눈 5, 나머지 2). 근거: 「一官成 十年之貴顯」(麻衣 p40).
5. 풀이는 원전 시의 좋은 뜻을 옮기고, 가장 긍정적으로 쓴다. 시에 섞인 단서(예: 虎眉 「鴈行虧」 형제가 이지러짐)는 첫 화면에 쓰지 않는다.

## 2-2. '재지 못하는 것'은 왜 있나 — 네 갈래

| 갈래 | 뜻 | 예 | 해결 |
|---|---|---|---|
| 정면 | 지금 정면 사진의 얼굴 점(478개)으로 잰다 | 눈 길이, 입꼬리, 눈썹 굽음 | 됨 |
| 스캔 | 높이·깊이·옆모습이라 정면 한 장으로는 추정만 된다 | 매부리코, 콧대 곧음, 눈동자 돌출, 귀 | 고개 돌리기 스캔 — **유료에서 해결** |
| 이미지 분석 | 얼굴 점이 아니라 털결·주름·눈꺼풀 처짐 같은 '질감'이라 별도 이미지 분석을 만들어야 한다 | 눈썹 털 밀도·방향(疏散·尖刀·旋螺), 입술 주름, 늘어진 눈꺼풀 | 만들 수 있다. 다만 화장·눈썹 문신·조명에 크게 흔들려 반복성 검사 후 채택 |
| 안 함 | 사진으로 재면 틀리는 것 | 빛깔(黃·紅), 눈빛(神), 흐림, 목소리, 기색 | 원전 스스로 "가장 살피기 어렵다(最爲難審)"고 한 것. 조명·카메라·화장에 따라 바뀌어 같은 사람도 매번 다르게 나온다 |

즉 진짜로 못 재는 것은 넷째 갈래(빛깔·눈빛·소리)뿐이고, 스캔·이미지 분석 갈래는 만드는 순서의 문제다.

제외한 좋은 형: 旋螺眉·前清後疏眉(이미지 분석), 胡羊鼻·蒜鼻(스캔).

## 3. 한계

- 모양 축의 기준값은 표준 얼굴 모델 값과 추정 표준편차다. 보정 데이터가 쌓이기 전에는 특정 형으로 몰릴 수 있다. 지인 표본으로 형별 분포를 먼저 본다.
- 첫 화면 형은 '닮은꼴'이다. 누구나 길한 형을 받는다. 흉한 형은 따로 걸러 쓴소리 칸에 싣는다.
- 사진 1명 5장 기준 반복성: 눈·눈썹·코는 5/5 같은 형, 입은 4/5.

## 5. 고개 돌리기 스캔 (구현 2026-10-07)

- 카메라: 정면(6장 이상) → 한쪽 → 반대쪽(각 약 9° 이상, 얼굴 점 기준 |yaw|>0.16). 25초 안에 못 하면 정면만으로 본다.
- 계산(`src/lib/scan.js`): 화면 가로 위치 x = s·(X·cosθ + D·sinθ) + t. 세로로 크기 s, 장면마다 θ 를 찾고, 모든 장면을 모아 점마다 깊이 D 를 푼다(번갈아 최소제곱). 표준 3D 얼굴 모델로 만든 가상 장면에서 각도 오차 3° 이내, 코 높이 등 깊이 오차 0.06(두 눈 안쪽 사이 거리 단위) 이내.
- 잰 값: 코 높이, 산근 높이, 콧대 가운데 높이, 콧대 혹(+)·꺼짐(−), 코끝 처짐, 눈 돌출, 턱 앞으로, 이마 솟음, 광대 높이.
- 스캔이 있으면 산근·콧대·광대 판정은 정면 추정 대신 스캔 값을 쓴다. 코의 옆모습 형(龍·懸膽·伏犀·截筒)은 스캔이 있을 때만 후보, 흉한 형 鷹嘴(혹+처짐)·劍鋒(좁고 높음)·三彎三曲(혹+꺼짐)·魚眼(눈 돌출)도 스캔이 있을 때만 판정.
- 한계: 고개를 위아래로 끄덕이면 오차가 커진다(좌우만 가정). 실제 사람 영상으로는 아직 검증 전 — 같은 사람을 여러 번 스캔해 반복성(ICC)을 먼저 본다. 기준값 평균은 표준 모델 실제 3D, 표준편차는 추정.
