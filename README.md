# 얼굴사주 (觀相 × 四柱)

얼굴(관상)에서 시작해 사주, 지금 있는 자리, 친구 관계도까지 이어서 풀어 주는 웹앱입니다.

## 흐름
1. **관상 풀이 (무료, 태어난 해만 선택 입력)**: 동의 체크 → 카메라(1초 동안 5장 평균) 또는 사진 →
   - 총평(가장 강한 궁·약한 궁, 키워드)과 오행형 얼굴
   - 유년운기: 세는 나이로 올해와 앞으로 4년 동안 운을 맡는 얼굴 자리와 길흉
   - 십이궁 10개 풀이(측정이 어려운 남녀궁·부모궁은 제외)와 주의 궁의 개운법
   - 관상도: 측정 비율만으로 얼굴을 다시 그려 십이궁도/유년운기도를 표시, 이미지로 저장 (`src/chart.js`)
   - 삼정(초년·중년·말년)과 오관
   - 덤: 왕기(王氣) 지수와 조선시대 직책
   - 결과 이미지 저장, 친구에게 공유
2. **관상 × 사주 (무료 1회 더)**: 생년월일 입력 → 얼굴 오행형과 사주 일간·부족 오행이 맞물리는지 해석
3. **유료 예정 (현재 잠금)**: 이 자리 풀이(방위·후천팔괘·오늘 일진), 친구 관계도. 주소 뒤에 `?all`을 붙이면 테스트용으로 열립니다.

풀이 로직은 `src/lib/reading.js`(십이궁·유년운기·삼정·총평)에 있습니다. 왕기 지수 = 좌우 대칭 + 삼정 균형 + 콧대 + 턱 + 눈꼬리 (`src/lib/king.js`). 기준 분포를 따른다고 가정하면 왕 판정(85점 이상)이 2~15%가 되도록 테스트로 고정해 두었습니다.

## 개인정보 설계
- 사진과 위치는 **서버로 전송하지 않습니다**. 모든 계산은 브라우저에서 합니다. 사진은 저장하지 않고, 측정 비율만 localStorage에 저장합니다.
- 초대 링크에는 생년월일 원본이 들어가지 않습니다. 일간, 일지, 오행 개수, 얼굴형만 담깁니다.

## 개발
```bash
npm install
npm run dev     # MediaPipe wasm·모델을 public/mediapipe 에 준비한 뒤 실행
npm test        # 사주·위치·궁합·EXIF 단위 테스트
npm run build   # dist/ 정적 배포물
```

## 알려진 한계 (출시 전 확인 필요)
- **관상 기준값**: 평균은 MediaPipe 표준 얼굴 모델에서 가져왔습니다. **표준편차는 추정치**라서, 실제 사용자 사진 수백 장으로 분포를 보정해야 오행형이 한쪽으로 쏠리지 않습니다(`src/lib/physiognomy.js`의 `BASE`).
- **사주**: 절기는 태양 황경으로 계산합니다(오차 수 분). 진태양시는 경도만 보정하고 균시차는 반영하지 않습니다. 서머타임은 1987~88년만 반영했습니다. 신강·신약과 부족 오행은 단순화한 계산이며, 용신이 아닙니다.
- **위치**: 위치정보법상 위치기반서비스사업 신고가 필요한지 법률 검토가 필요합니다(현재는 기기 밖으로 전송하지 않는 구조).
